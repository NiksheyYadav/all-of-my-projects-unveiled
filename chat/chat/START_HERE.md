## ⚡ QUICKEST START (2 Minutes)

### What You Need:
1. An OpenRouter API key (free to get, pay-as-you-go)

### Steps:
1. **Get API Key**:
   - Visit: https://openrouter.ai
   - Sign up (free)
   - Go to "Keys" tab → Create Key
   - Add $5 credits (lasts ~2,500 messages)

2. **Add to `.env.local`**:
   ```env
   OPENROUTER_API_KEY=sk-or-v1-YOUR_KEY_HERE
   ```

3. **Start App** (if not running):
   ```bash
   npm run dev
   ```

4. **Open Browser**:
   - http://localhost:3000
   - Click "Start Chatting"
   - Type a message
   - Watch the magic! ✨
